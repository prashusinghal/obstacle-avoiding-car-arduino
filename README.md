# 🚗 Obstacle Avoiding Car using Arduino

An autonomous robotic car that detects obstacles using ultrasonic sensors and automatically avoids collisions.

---

## 📌 Overview

This project demonstrates the implementation of an intelligent obstacle avoiding robotic vehicle using Arduino Uno, ultrasonic sensor, and motor driver module.

The robot continuously scans its surroundings and takes real-time decisions to navigate safely without human intervention.

---

## ✨ Features

- Autonomous navigation
- Obstacle detection
- Real-time decision making
- Automatic direction control
- Low-cost robotics project

---

## 🛠 Components Used

- Arduino Uno
- HC-SR04 Ultrasonic Sensor
- L298N Motor Driver
- DC Motors
- Robot Chassis
- Li-ion Battery

---

## ⚙ Working Principle

The ultrasonic sensor continuously measures distance.

- If obstacle detected:
  - Stop
  - Move backward
  - Scan left and right
  - Choose safer path

- If path clear:
  - Move forward
